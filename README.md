# UC5 - Compare Two Length Quantities

## Description
Ability to compare two length quantities even if they are in different units.  
The comparison is done by converting both values into a common base unit.

## Supported Units
- Inch
- Feet
- Yard
- Centimeter

## Example
1 Feet = 12 Inches  
3 Feet = 1 Yard  

## Implementation Steps
1. Convert both quantities to a base unit (Inches).
2. Compare the converted values.
3. Return true if equal, otherwise false.

## Sample Scenario

Input:
1 Feet and 12 Inches

Output:
True (Both represent the same length)
