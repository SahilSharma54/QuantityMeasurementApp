# UC6 - Add Two Length Quantities

## Description
Ability to add two length quantities even if they belong to different units.

## Supported Units
- Inch
- Feet
- Yard
- Centimeter

## Implementation Steps
1. Convert both values into the base unit (Inches).
2. Add the converted values.
3. Convert the result into the required unit.

## Example

1 Feet + 2 Inches

Conversion:
1 Feet = 12 Inches

Calculation:
12 + 2 = 14 Inches

Output:
14 Inches
