# UC9 - Introduce Temperature Measurement

## Description
Add temperature measurement support and conversion between Celsius and Fahrenheit.

## Supported Units
- Celsius
- Fahrenheit

## Conversion Formula

Celsius to Fahrenheit

F = (C × 9/5) + 32

Fahrenheit to Celsius

C = (F − 32) × 5/9

## Example

0°C = 32°F  
100°C = 212°F
