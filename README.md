# UC7 - Introduce Weight Measurement

## Description
Add support for weight measurement along with comparison functionality.

## Supported Units
- Gram
- Kilogram
- Tonne

## Conversion Rules
1 Kilogram = 1000 Gram  
1 Tonne = 1000 Kilogram

## Implementation Steps
1. Convert both weight values into the base unit (Gram).
2. Compare the converted values.

## Example

1000 Gram = 1 Kilogram

Output:
True
