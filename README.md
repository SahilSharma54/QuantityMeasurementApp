# UC8 - Add Two Weight Quantities

## Description
Ability to add two weight quantities even if they belong to different units.

## Supported Units
- Gram
- Kilogram
- Tonne

## Implementation Steps
1. Convert both values into the base unit (Gram).
2. Add them.
3. Convert the result into the required unit.

## Example

1 Kilogram + 500 Gram

Conversion:
1 Kilogram = 1000 Gram

Calculation:
1000 + 500 = 1500 Gram

Output:
1500 Gram
