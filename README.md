# UC10 - Add Two Temperature Quantities

## Description
Ability to add two temperature values after converting them into a common unit.

## Supported Units
- Celsius
- Fahrenheit

## Implementation Steps
1. Convert both temperatures into a base unit (Celsius).
2. Add the values.
3. Convert the result into the desired unit if required.

## Example

25°C + 10°C

Calculation:
25 + 10 = 35°C

Output:
35°C
